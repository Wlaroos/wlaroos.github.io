Skele-Cat

Skele-Cat is a solo jam project where you play as a cat that explodes and uses blood to create platforms. Originally born from a 48-hour prototype, this project explores unique movement mechanics and high-stakes platforming.

Software Used

  • Unity
  • Aseprite
  • Photoshop
  • Github (Version Control)

Project Type
